Script en PowerShell para automatizar respaldos en servidores Windows

Dejo este snippet que comprime carpetas específicas de logs y las sube automáticamente a un bucket de S3 usando tareas programadas. Ahorra muchísimo tiempo los viernes.

Compress-Archive -Path C:\Logs\* -DestinationPath C:\Backups\logs_$(Get-Date -f "yyyyMMdd").zip
